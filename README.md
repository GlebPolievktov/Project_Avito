# Нормализатор числительных для транскрибаций Avito

## Описание проекта

Система для автоматической нормализации числительных в текстах транскрибаций телефонных разговоров. Преобразует числа, записанные словами, в цифровой формат с учетом ошибок автоматической расшифровки речи.

**Примеры работы:**
- "бюджет гдето триста пятьдесят тысяч" → "бюджет гдето 350000"
- "на двадцать три дня" → "на 23 дня"
- "двеси шестьдесят пять рублей" → "265 рублей"

## Структура проекта

### Основные файлы

#### `normalize.py`
Основной модуль с классом `NumberNormalizer` для нормализации числительных.

**Класс NumberNormalizer:**
- `__init__()` - инициализация словарей числительных и искаженных вариантов
- `normalize_text(text: str)` - главная функция нормализации текста
- `setup_dictionaries()` - создание словарей базовых числительных и их искажений
- `tokenize_text(text: str)` - разбивка текста на токены
- `find_number_tokens(tokens)` - поиск числительных в токенах
- `fuzzy_match_number(word: str)` - нечеткое сопоставление с числительными
- `group_composite_numbers(number_tokens)` - группировка составных чисел
- `apply_replacements(tokens, groups)` - применение замен и сборка результата

#### `analyze.ipynb`
Jupyter notebook для анализа данных и тестирования алгоритма.

**Основные функции:**
- `analyze()` - анализ калибровочных данных, выявление паттернов и ошибок
- `generate_final_answer()` - применение нормализатора к тестовым данным
- Статистический анализ частоты числительных и искажений
- Визуализация примеров работы алгоритма

### Файлы данных

- `calibration.f` - калибровочные данные с парами (исходный_текст, целевой_текст)
- `test.f` - тестовые данные для финальной обработки
- `answer.csv` - результат работы алгоритма на тестовых данных

## Алгоритм работы

### 1. Токенизация
Разбивка входного текста на отдельные слова.

### 2. Поиск числительных
- Точное сопоставление с базовыми словарями
- Обработка искаженных вариантов ("двеси" → "двести")
- Нечеткий поиск с использованием `difflib.SequenceMatcher`
- Фильтрация ложных срабатываний через черный список

### 3. Группировка составных чисел
**Правила композиции (по приоритету):**
1. Число + множитель: "двести тысяч" → 200000
2. Тысячи + меньшие числа: "две тысячи пятьсот" → 2500  
3. Сотни + десятки/единицы: "двести пятьдесят" → 250
4. Десятки + единицы: "двадцать три" → 23

**Ограничения:**
- Не группировать через разделители: "до", "или", "и", "тире"
- Максимальное расстояние между числами: 3 токена

### 4. Применение замен
Замена найденных групп числительных на цифровые эквиваленты с сохранением остального текста.

## Технические особенности

### Словари
- **Базовые числительные**: 1-999, тысячи, миллионы
- **Порядковые числительные**: первый, второй, третий...
- **Искаженные варианты**: двеси→двести, тыщ→тысяч, петьдесят→пятьдесят
- **Черный список**: обычные слова для предотвращения ложных срабатываний

### Параметры
- Порог нечеткого поиска: 0.85
- Минимальная длина слова для нечеткого поиска: 4 символа
- Максимальное расстояние для группировки: 3 токена
